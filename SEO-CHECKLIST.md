# SkyView Website - SEO & AI-Readability Checklist

Use this checklist when adding new pages, content, or making updates.

## 📋 Pre-Launch Content Checklist

### Content Quality
- [ ] Content clearly answers a specific user question or search intent
- [ ] Minimum 300-500 words for service pages (more for guides)
- [ ] Uses clear, explicit language without ambiguity
- [ ] Includes specific facts and numbers (not vague estimates)
- [ ] Content is factually accurate (verify sources)
- [ ] Content is unique (not duplicated from other pages)

### Semantic HTML Structure
- [ ] Uses proper heading hierarchy (h1 → h2 → h3, no skipping levels)
- [ ] First h1 tag appears as main page title
- [ ] Headings describe the section content
- [ ] Content organized with lists (ul/ol) where appropriate
- [ ] Uses semantic elements (section, article, aside, etc.)
- [ ] No div-based layouts for content structure

### Images
- [ ] All images have descriptive alt text
- [ ] Alt text is 125 characters or less
- [ ] Alt text describes what's in the image and why it matters
- [ ] Images are compressed and optimized
- [ ] Images are in modern format (WebP with fallbacks)
- [ ] No purely decorative images without context

### Metadata
- [ ] Title tag is unique and descriptive (40-60 characters)
- [ ] Meta description is unique and compelling (120-160 characters)
- [ ] Page URL is clean and keyword-rich (use hyphens, not underscores)
- [ ] Keywords are relevant to content (3-5 primary keywords)
- [ ] Open Graph image is prepared (1200x630px)

### Links
- [ ] Internal links use descriptive anchor text (not "click here")
- [ ] External links are to authoritative sources
- [ ] No broken links (404s)
- [ ] Links open in same tab (not new window, unless necessary)

## 🔍 Schema & Structured Data Checklist

### JSON-LD Implementation
- [ ] Schema type matches content (Service, FAQ, etc.)
- [ ] All required properties are included
- [ ] Structured data validates at https://schema.org/validate
- [ ] Schema appears in Google's Rich Results Test
- [ ] Schema is in `<script type="application/ld+json">` tags

### Organization/LocalBusiness Updates
- [ ] Company information is current
- [ ] Address is correctly formatted
- [ ] Phone number matches website contact info
- [ ] Service areas are accurate
- [ ] Social media profiles are current

### Service Schema
- [ ] Service name is clear and specific
- [ ] Service description matches page content
- [ ] Service type is correctly specified
- [ ] Provider information is accurate
- [ ] Service area (areaServed) is specified

### FAQ Schema
- [ ] Questions are actual user questions
- [ ] Questions match FAQ section on page
- [ ] Answers are complete and accurate
- [ ] Minimum 1 Q&A pair (more is better)
- [ ] Uses "Question" and "acceptedAnswer" structure

## 🎯 SEO Performance Checklist

### Search Visibility
- [ ] Page is indexed in Google Search Console
- [ ] Page appears in XML sitemap
- [ ] Page is not blocked by robots.txt
- [ ] No noindex tag on page
- [ ] Canonical URL is set correctly

### Keyword Optimization
- [ ] Primary keyword appears in title tag
- [ ] Primary keyword appears in first 100 words
- [ ] Primary keyword appears in first heading (h1)
- [ ] Related keywords appear naturally throughout content
- [ ] Keyword density is 1-2% (not keyword stuffed)

### User Experience
- [ ] Page loads in under 3 seconds (Core Web Vitals)
- [ ] Mobile experience is optimized (responsive design)
- [ ] Navigation is clear and intuitive
- [ ] Call-to-action is visible above the fold
- [ ] Text is readable (sufficient color contrast)

## 🤖 AI-Readability Checklist

### Information Extraction
- [ ] Facts can be easily extracted from lists
- [ ] Comparisons are structured (table-like or parallel)
- [ ] Key information is labeled clearly
- [ ] No important info hidden in images only
- [ ] Definitions appear before specialized terms

### Content Organization
- [ ] Content follows a logical flow
- [ ] Related information is grouped together
- [ ] One idea per paragraph
- [ ] Categories are clearly labeled
- [ ] No run-on sentences (break into smaller units)

### Technical Implementation
- [ ] No JavaScript required to read main content
- [ ] Content is in HTML, not images
- [ ] Structured data complements but doesn't replace text
- [ ] Robots meta tag allows crawling
- [ ] No blocking of resources in robots.txt

## ✅ Quality Assurance

### Before Publishing
- [ ] Preview page in multiple browsers
- [ ] Test on mobile devices (phone, tablet)
- [ ] Check all links work (internal and external)
- [ ] Verify images load and display correctly
- [ ] Test form submissions (if applicable)
- [ ] Spell-check and grammar review (Hebrew language)

### After Publishing
- [ ] Submitted to Google Search Console
- [ ] Checked in Rich Results Test
- [ ] Validated schema markup
- [ ] Monitored in Google Analytics
- [ ] Tested in Rich Results Test (24-48 hours later)

## ❓ Common Questions

### "Should I use keywords in alt text?"
Yes, but naturally. Alt text should describe the image content AND include relevant keywords when appropriate. Example: "תקרה מתוחה מוארת בסלון" (glossy illuminated stretch ceiling in living room)

### "How many keywords per page?"
Focus on 1 primary keyword and 3-5 related keywords. Don't exceed 2% keyword density.

### "What's the ideal content length?"
- Service pages: 500-1000 words
- Blog posts: 1500-3000 words
- Guides: 2000-5000 words
- Keep paragraphs under 150 words

### "Do I need to update old content?"
Yes, review and update annually or when information becomes outdated. Mark update date in metadata and schema.

### "Should all internal links be keyword-rich?"
No, use natural anchor text. Mix keyword-rich links with descriptive phrases. Avoid "click here" style links.

## 🆘 Troubleshooting

### Rich Results not showing
1. Validate schema at https://schema.org/validate
2. Check Google's Rich Results Test
3. Wait 2-4 weeks for Rich Results to appear
4. Check Search Console for any issues

### Low search traffic
1. Verify page is indexed
2. Check Search Console for keyword data
3. Review page title and meta description
4. Ensure content matches search intent
5. Build internal links to page

### Page not indexing
1. Check robots.txt
2. Check for noindex tag
3. Verify no crawl errors in Search Console
4. Request indexing in Search Console
5. Check for authentication requirements
